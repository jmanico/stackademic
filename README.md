# stackademic

A Texas Hold'em strategy site for players who already know the game. It teaches through hand quizzes, practice hands, win probability, one-on-one tutoring, and bluffing lessons. No real money is involved.

## Design in brief

The product is styled as a study desk, not a casino. Each hand is laid out like a worked problem: the cards, the board, a strip of seats, and the action so far. Cards use a four-color deck (spades in ink, hearts red, diamonds blue, clubs green), and highlighter yellow marks the user's own choices. The typeface is Atkinson Hyperlegible Next, and every color pair meets WCAG 2.2 AA.
